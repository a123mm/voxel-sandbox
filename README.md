# 方块世界 · 网页体素沙盒

> 🎮 **在线试玩**：https://a123mm.github.io/voxel-sandbox/
> 📦 源码：https://github.com/a123mm/voxel-sandbox


纯前端、零构建的体素沙盒游戏：单个 HTML + 一个 JS，除本地 `three.min.js` 外无任何依赖。
手机浏览器可直接玩，支持触摸摇杆、长按连续挖掘、独立「挖/放」按钮。

> 原创作品，非 Minecraft 复刻；不含任何 Mojang 素材。

## 快速开始

```sh
cd ~/deep/voxel-web
python3 -m http.server 8123 --bind 0.0.0.0
```

- 电脑：`http://127.0.0.1:8123/`
- 手机：同一 Wi-Fi 下打开 `http://<局域网 IP>:8123/`

三套材质可直接用地址切换：`?theme=round`（默认，原创圆润）/ `?theme=pack`（手绘 CC0）/ `?theme=classic`（经典 CC）。

## 保持屏幕常亮（无 root）

游戏内：**菜单 → 常亮:开**。用的是浏览器 Screen Wake Lock API，切到后台会自动释放、回到前台自动重申请。

> 该 API 需要「安全上下文」：在手机上打开 `http://127.0.0.1:8123/` 即可；
> 用 `http://<局域网 IP>:8123/` 打开时浏览器不提供，按钮会显示「不支持」。

命令行（`sh keep_awake.sh ...`）：

| 命令 | 作用 |
|---|---|
| `sh keep_awake.sh cpu` | Termux CPU 唤醒锁：屏幕仍会熄灭，但服务/网络不会被挂起 |
| `sh keep_awake.sh release` | 释放 CPU 唤醒锁 |
| `sh keep_awake.sh adb-on` | `svc power stayon true`（需先开无线调试）充电时屏幕常亮 |
| `sh keep_awake.sh info` | 三种方式说明 |

注意：普通 Termux 进程直接 `settings put system screen_off_timeout` 会被 Android 拒绝
（`SecurityException: 缺 INTERACT_ACROSS_USERS`），所以改系统设置必须走 `adb shell`。

## 功能

**世界**
- 无限区块流式加载（16×16×32），确定性噪声地形、洞穴、煤矿/铁矿、树、花草
- 沙漠/草原生物群系（地表材质与植被不同）
- 昼夜循环（10 分钟一天）、日月、星空、雾色随天色变化
- 水面透明渲染，水下可游泳（空格上浮，入水不摔伤）
- 火把照明：**BFS 泛光**（可绕墙、有遮挡、逐级衰减），网格颜色按光照栅格着色 + 加法发光层
  - 合成：木×1 + 煤×1 → 火把×4（背包里可做）
  - 性能：只有火把 13 格内的区块才真正跑 BFS，其它区块零开销；编辑方块/火把时按 3×3 区块失效重算
- 被动生物：羊 / 猪各 4 只，会随机游荡、怕人（靠近会跑开）、掉进虚空或离太远自动回收

**生存**
- 10 颗心（20 点血）：摔落伤害（超过 3.6 格）、溺水、受伤红屏、死亡自动重生
- 12 秒不受伤后缓慢回血；水下有氧气条
- 挖到的方块进背包，放置消耗

**建造**
- 19 种方块：草/土/石/沙/水/木/叶/木板/煤/铁/圆石/工作台/石砖/玻璃/花/草/火把/石台阶/木台阶
- 台阶半砖：高度 0.5，可站上去、可从侧面挡人；同种台阶叠放会变成完整方块
- 简易合成（木→木板、木板→工作台）+ 工作台合成（圆石→石砖、沙→玻璃）

**界面**
- 小地图（高度明暗、玩家朝向箭头）、FPS/坐标/时间信息
- 暂停面板：存档、导出/导入存档、**3 个存档槽**、音效、小地图、飞行、屏幕常亮、性能面板（F3）、时间（黎明/正午/黄昏/夜晚）、视距、材质
- 自适应画质：帧率过低自动降分辨率与视距（保护手机 GPU）

**音效（纯程序化，无音频素材）**
- 脚步、挖掘（按材质变调）、放置、合成、UI、受伤

## 存档

- 位置：`localStorage` 键 `voxel_world_v3`
- 版本 `v4` 字段：`px/py/pz` `yaw/pitch` `sel/fly` `inv` `hp` `t`（时间）`sx/sy/sz`（出生点）`ch`（区块改动）
- 兼容 `v3` 旧档（缺省血量/时间）
- 暂停面板可导出为 `voxel-world-HHMM.json`，也可导入（自动重载）

## 已知限制

- 没有光照传播系统：夜晚靠整体调暗，暂无火把/灯光
- 没有生物/怪物/掉落物
- 建网格在主线程（按 5ms 时间预算分帧），视距 5 时首次进入会有短暂卡顿
- 手机 GPU 偶发不稳定：如遇白屏/黑屏，进「菜单」把视距调到 2~3
- 屏幕常亮依赖浏览器支持；部分浏览器/低版本 WebView 不提供 Screen Wake Lock
